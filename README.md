# Invitación Encanto — Ross Digital Studio

Versión modernizada y reorganizada del modelo temático Encanto.

## Estructura

- `index.html`: estructura principal.
- `css/styles.css`: diseño responsive y estética temática.
- `js/config.js`: datos editables de la invitación.
- `js/app.js`: música, personajes, contador, WhatsApp y animaciones.
- `assets/img`: fondos, personajes, foto y recursos visuales.
- `assets/audio`: música.
- `assets/fonts`: tipografía temática.

## Personalización rápida

Los datos del evento se cambian en `js/config.js`: nombre, edad, mensaje, fecha, horario, lugar, dirección, Maps, WhatsApp e Instagram.

## Funciones

Pantalla de entrada con audio, personajes rotativos, contador regresivo, ubicación, confirmación por WhatsApp, animaciones de scroll, responsive mobile-first y firma de @rossdigitalstudio.

Diseñado por Ross Digital Studio.
